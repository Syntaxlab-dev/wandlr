How we guarantee this

01

No network requests carry your files

Every file is read straight into memory and processed with your browser's own APIs. Open your browser's network tab while converting — you'll see it stays empty.

02

Fully open source

The entire source is public. Read it, run it yourself, or host your own copy — nothing is hidden.

03

Just your browser, no black box

Images are re-encoded with the browser's built-in Canvas API. PDFs use two well-known open-source libraries, loaded once and then run entirely offline in memory.
